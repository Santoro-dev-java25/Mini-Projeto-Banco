# Sistema Bancário em Java

## Sobre o projeto

Este foi meu primeiro projeto utilizando Programação Orientada a Objetos (POO) em Java, desenvolvido durante meus estudos.

O objetivo foi aplicar os conceitos iniciais da orientação a objetos por meio de um sistema bancário simples, realizando operações básicas em uma conta.

## Tecnologias

- Java

## Conceitos utilizados

- Classes
- Objetos
- Atributos
- Métodos

## Funcionalidades

- Criar uma conta bancária
- Realizar depósitos
- Realizar saques
- Consultar o saldo da conta

## Objetivo

Este projeto foi desenvolvido com o objetivo de praticar os primeiros conceitos de Programação Orientada a Objetos em Java.
